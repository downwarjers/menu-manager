# 餐廳菜單管理系統

單頁式純靜態餐廳菜單與通路定價管理工具，支援多通路利潤加成計算、自動取整與備份匯出。

## 線上訪問網址
https://downwarjers.github.io/menu-manager/

## 主要功能
- 料理與套餐組合維護
- 通路加成率與專屬尾數進位（四捨五入、進位 5、尾數 8/9、進位至十位）
- 本地資料儲存（LocalStorage）
- 菜單 CSV 匯出與完整 JSON 備份/匯入

## 技術架構
- 核心框架：Vue 3 (CDN, ES Module)
- 樣式引擎：Tailwind CSS (CDN)
- 託管環境：GitHub Pages (純靜態託管，無需 Build 流程)
